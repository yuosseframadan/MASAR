# MASAR — مسار | NexCode

تطبيق ويب تقدّمي (PWA) عربي/إنجليزي لتنظيم المهام والعادات والمنبّهات محليًا على الجهاز.

## التشغيل والتجربة

1. فك ضغط `MASAR_PWA_Release.zip`.
2. على Windows يمكنك تشغيل `start-windows.bat`، أو شغّل خادمًا محليًا من داخل المجلد:
   - Python: `python -m http.server 8000`
   - أو انشر المجلد على استضافة HTTPS.
3. افتح `http://localhost:8000`.
4. من قائمة المتصفح اختر تثبيت التطبيق / Add to Home Screen عند توفرها.

> لا تفتح `index.html` مباشرة عبر `file://`؛ التثبيت والعمل دون اتصال يحتاجان `localhost` أو HTTPS.

## الموجود في هذه النسخة

- مهام وعادات ومنبّهات مستقلة، مع ملاحظات وتواريخ وأوقات وأولوية ونغمة وتكرار.
- مسارات فرعية، حالات إنجاز/عدم إنجاز، وتسجيل أحداث في السجل.
- أرشيف واسترجاع، تقويم، بحث وفلاتر، وإحصاءات أساسية.
- واجهة عربية/إنجليزية RTL/LTR، وثيم فاتح/داكن، وتصميم متجاوب.
- حفظ محلي عبر IndexedDB، وتصدير واستيراد نسخة احتياطية JSON.
- قفل PIN/كلمة مرور محلي، وطلب إذن الإشعارات.
- PWA وService Worker وأيقونات مأخوذة من شعار مسار.
- تذييل رابط NexCode.

## حدود مهمة — اقرأ قبل النشر

- إشعارات وتنبيهات الوقت تعمل أثناء فتح التطبيق؛ لا يمكن ضمان عملها في الخلفية أو بعد إغلاق التطبيق على كل أنظمة التشغيل عبر PWA فقط. الدعم يختلف بين المتصفح والمنصة، وقد تتطلب تنبيهات موثوقة بالخلفية تطبيقًا أصليًا أو خدمة جدولة مناسبة.
- قفل PIN الحالي طبقة واجهة تعتمد على بصمة SHA-256، وليس تشفيرًا لقاعدة البيانات. لا تعتبره حماية جنائية أو مناسبة لبيانات شديدة الحساسية.
- دعم البصمة عبر WebAuthn غير مفعّل في هذه النسخة.
- البيانات محلية على كل جهاز ولا توجد مزامنة سحابية. استخدم النسخ الاحتياطي لنقل البيانات أو حمايتها من الفقد.
- اجتازت الحزمة فحصًا ساكنًا لصياغة JavaScript ومعرّفات DOM وملف manifest والأيقونات؛ لم يُستكمل اختبار متصفح آلي، ويلزم اختبار يدوي على أجهزة iOS وAndroid وWindows وmacOS وLinux قبل الإطلاق العام.
